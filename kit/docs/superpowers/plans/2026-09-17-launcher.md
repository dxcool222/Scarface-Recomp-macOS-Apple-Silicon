# Launcher plan

Spec: `../specs/2026-09-17-launcher-design.md`. Branch: kit `launcher`, then
`main`; game repositories re-pin once it is on `main`.

## L0: core (done)

- `platform/`: `os_free_space`, `os_set_mtime`, `os_registry_read`.
- `third_party/miniz` for ZIPs.
- `game.toml [launcher]`, `RECOMP_LAUNCHER_*`, `RECOMP_REQUIRED_DIRS`,
  `RECOMP_BUNDLE_EXCLUDE` (`tests/test_game_config.py`).
- `host/launcher/launcher.{h,cpp}`: find, check, import (folder, ZIP, move),
  remembered folders, save export and import, install detection
  (`host/tests/launcher_tests.cpp`).
- `runtime/layout.cpp` follows a `RECOMP_PROFILE_DIR` set after the first
  question (Android set it after a constructor had asked).

## L1: desktop (done)

- `host/launcher/launcher_ui.*` (model, tested without SDL),
  `launcher_canvas.*`, `launcher_sdl.*`, `launcher_platform_desktop.cpp`.
- `host/sdl/main.cpp` shows it when the game is missing or wrong, on
  `--launcher`, `RECOMP_LAUNCHER`, Shift or Alt; `RECOMP_LAUNCHER_DUMP` and
  `RECOMP_LAUNCHER_KEYS` for smoke runs.
- Checked: the stub app shows "Game not found"; Pharaoh on macOS refuses an
  empty folder, accepts a dropped install, remembers it and starts the game.

## L2: Android (done)

- `RecompActivity`: folder, ZIP and save-as pickers, tree listing,
  descriptors, "Open with" a ZIP; `ImportService` (dataSync foreground
  service); stdout and stderr in logcat; 16 KB page aligned libraries.
- Checked on the Pixel 10 Pro emulator (API 37, no Vulkan, so the software
  launcher): folder picker import, ZIP picker import, delete, a folder copied
  into the files directory moved into place, "Open with", save export.
  Not checked: starting the game after the launcher (needs Vulkan).

## L3: iPadOS (done)

- `host/sdl/platform_ui_ios.mm`: `Documents/game` first, the bundle imported
  when it is missing, document pickers (security-scoped), Finder and Files
  copies moved into place, iCloud backup exclusion, the share sheet for saves,
  a 1.5 s countdown before a ready game starts.
- Checked on an iPad Pro (M4) with Pharaoh: an existing import is ready, a
  folder copied into Documents is moved into place and removed, Play starts
  the game, the countdown starts it without a touch.
  Not checked: the document pickers themselves (they need a finger).

## L4: web (done)

- `web/launcher/` (hub page, worker, `core.js`), `tools/web_launcher.py`
  (`tests/test_web_launcher.py`, `node --test web/launcher/tests`).
- Checked in Chrome: folder import, ZIP import, a ZIP of another game refused,
  save export, two-step delete keeping saves, Play explaining that the web
  build is missing. The web build of a game (the WebAssembly target) is
  separate work.

## Rollout

- Kit `main` fast-forwards to `launcher`; Populous, Majesty and Pharaoh
  re-pin with `[launcher]` data and are checked (build, smoke, Populous
  gameplay and mod suites).
- Siege and NFSMW: the same commits on their kit branches, handed to the
  sessions that own those pins, with their `game.toml` data.
